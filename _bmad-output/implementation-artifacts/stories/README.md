# Stories Folder Guide

Use this structure for lifecycle tracking:

- `backlog/`
- `ready/`
- `in-progress/`
- `blocked/`
- `review/`
- `done/`
- `_templates/`

## Create a New Story

1. Copy `_templates/dev-story-template.md` to `backlog/`.
2. Fill all placeholders.
3. Add/update row in `_bmad-output/planning-artifacts/story-management-board.md`.
4. Move file between folders when status changes.

## Status–Folder Rule

Status in file must match folder name:

- `Backlog` -> `backlog/`
- `Ready` -> `ready/`
- `In Progress` -> `in-progress/`
- `Blocked` -> `blocked/`
- `Review` -> `review/`
- `Done` -> `done/`
